# Drift Core 0.1.0
Shared Flutter engine extracted from Art Drift main @ d329161c88f26eadf30e3f2ad3452c6e36aac604 with no intentional visual/gesture changes.

- Deterministic infinite-column layout and up to 180 mounted tiles.
- Pinch, pan, kinetic fling, recenter, persisted named camera.
- Generic source adapter through DriftCanvas<T>.tileBuilder and onOpen.
- No media API, account, AdMob, billing, image assets or permissions.
- Art Drift consumes as local path; Gallery Drift pins a Git SHA subdirectory package.
- Shared improvements are committed here and promoted by coordinated PR/CI; no bidirectional copy-paste.

Original widget code remains user-owned. Golden candidate canvas is not claimed certified.
