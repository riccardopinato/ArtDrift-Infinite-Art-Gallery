## Safety and evidence constraints

1. Closing a PR **does not merge its code**. The unchanged historical PR URL and exact HEAD SHA are retained as recoverable source evidence. Do **not** delete source branches/PR refs, images, research files, or GitHub Actions evidence. Artifacts may expire, so use committed code/research data as durable source, not a workflow artifact alone.
2. This ledger is a **source index**, not a claim that all historical data/scripts are already copied onto `main`. On recovery: inspect exact commit/tree, extract only verified unique data/code to current `main` via a NEW small PR and exact-head test.
3. Rights/provenance **HOLD** remains HOLD. Metadata CC0 does not license a specific reproduction, and CI PASS does not certify publication. Do not enable catalog flags, import 283/485 files or publish 161k MoMA entries based on this cleanup.
4. Preserve source-native IDs and user camera coordinates; no mass duplicate catalog import or replacement of `web/museum_thumbs` (4,042 WebP already integrated via #55 with #87 QA).
5. Shared Drift Core changes require independent GalleryDrift pinned consumer CI and visual/device acceptance; cloud-auth remains under privacy/security gate. No public release authorized.
6. The retained PRs are **owners of remaining work**, not necessarily mergeable as-is. Do not close an owner until its capability is merged or an explicit replacement/decision is recorded.
