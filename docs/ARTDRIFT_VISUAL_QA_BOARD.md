ART_ONLY visual QA wave. This branch actually decodes all 457 existing locally bundled images using pinned Pillow, detects byte duplicates and significant aspect mismatch, then writes an inspectable 100-card HTML image board with museum/artist/identity. A bounded maximum of 12 remote reference previews is attempted only on historical source CC0/public-domain works and strict museum URL allowlists. Provider HTTP/CORS failures are logged as NOT_VERIFIED; no image is forged, cropped into original, or silently accepted. 585 new Smithsonian/Commons candidates remain no-image HOLD. This is NOT a Flutter on-device screenshot parity test and does NOT approve the ten design mockups; those remain a separate human visual review gate. Never use this artifact as legal certification. No APK, no production updates or cloud writes.
