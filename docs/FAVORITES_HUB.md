# Art Drift favorites hub (v0.3.1)

- Heart added beside the gear in the existing parchment top toolbar.
- Search stays precisely 1/3 of screen width in the approved design.
- Parchment favorites shelf with saved artwork list, empty state, remove action,
  and opening the standard immersive artwork detail on tapping a row.
- Retains original integer AIC favorites via keys migration to source-qualified
  catalog keys; saves snapshots for remote museum search favorites across app restarts.
- Six localized interface languages: it, en, fr, es, de, pt.
- No changes to Drift Core, canvas/gestures, Gallery Drift media permissions,
  advertising, payments, or Play distribution.
- QA gates: analyze, test (migration, remote, toolbar, shelf, localization),
  Android internal ARM64 APK and later physical visual acceptance.
